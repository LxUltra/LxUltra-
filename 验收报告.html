1.2 缺陷清单（本次新增代码，按级别）

级别位置问题触发条件修复状态
Criticalapp_wrapper.py ns['__name__']注入命名空间用了 'app_orig'，而原模块尾部有 if __name__=='__main__' 守卫 → main() 永不执行，进程秒退（退出码 0、无窗口）任何启动改为 '__main__'，与原行为一致已修/已验证
Criticalbuild_patched.py重建归档时漏写原 exe 的 PE 头 + bootloader 前缀 → "不是有效应用程序"任意构建保留 data[:archive_start] 前缀，并加 MZ / archive_start 双重自校验已修/已验证
Criticalapp_wrapper.py _protected_partition系统盘上的 启动/系统/EFI/MSR/恢复 分区缺少分区级守卫，仅盘级拦截对系统盘保护分区执行删除/格式化/改盘符新增实时 PS 查询分区标志，命中即拒绝已修/已测
Majorpartition_ui.js openModal()返回 undefined，但调用处写成 openModal(...).then(...) → 所有弹窗确认回调失效（reading 'then'）任意弹窗确认openModal 返回 Promise 并自动接线按钮已修/已测
Majorapp_wrapper.py _op_guard对 benchmark/scan/defrag/set_label/vhd_* 强制要求 disk 字段 → 全部被误拒（"缺少有效的磁盘编号"）测速/检查/整理/改卷标/VHD按 _DISKLESS_OPS 分类校验已修/已测
Majorapp_wrapper.py partition_job_submit非法操作（缺字段/未知类型）仍创建任务，只在执行期报错非法入参新增 _validate_op 前置校验，逐项报错并拒绝建单已修/已测
Minorapp_wrapper.py _wrap_log引用未导入的 tempfile，异常被静默吞掉 → 日志全丢，排障失明首次写日志改用 LOCALAPPDATA/TEMP 并导入 tempfile；顶层加 traceback 落盘已修
Minorpartition_ui.js 结果区执行结果显示 "测试 undefined"（结果对象只有 type，无盘符上下文）任务完成渲染后端结果回带 op，前端 opLabel(r.op||…)已修/已测

6.2 残留风险（明确标注）

风险说明处置
破坏性操作未做真机实测删除分区 / 删除所有分区 / 擦除 / 快速分区 / 转换分区表 —— 不可逆，验收中刻意未对真实磁盘执行（仅验证代码路径、参数构造与守卫）首次使用请在无数据磁盘或已备份磁盘上验证；建议逐步：先试「快速分区」于空盘
克隆硬盘/克隆分区安全停用文件级克隆需专用引擎，当前直接返回「实验功能停用」，避免误操作如需启用，后续单独开发 + 独立验收
应用更新会覆盖前端分区助手前端位于 _internal\inventory（index.html / partition_ui.js / partition_ui.css），应用内「检查更新」若覆盖 _internal 会丢失原版与改版均已备份在 D:\Codex\LxUltra-PartitionAssistant\_backup_original，重跑 build_patched.py + 复制前端即可恢复；建议更新前备份 _internal
GUI 进程不可被代理长驻代理沙箱会回收其派生的 GUI 子进程，验收时通过「启动日志 + 进程存活判定」证明可用日常请双击桌面「LxUltra电脑管家」启动
需管理员权限破坏性操作要求管理员；非管理员时按钮可点但后端返回明确拒绝右键以管理员身份运行，或确认应用自身提权
